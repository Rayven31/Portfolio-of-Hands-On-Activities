$\Large\textcolor{#2ea44f}{\textbf{algorithm basic analysis}}$

Learn how to measure a program's performance. You will understand how to calculate time complexity to predict how fast your code will run as your input data grows larger.

$\Large\textcolor{#2ea44f}{\textbf{arrays pointers and DMA}}$

Understand how computers store lists of items in memory. You will learn how pointers hold memory addresses and how DMA lets your program request or free up memory while it is running.

$\Large\textcolor{#2ea44f}{\textbf{Link lists basics}}$

Discover how to create a flexible chain of data nodes connected by pointers. This topic covers how to insert, delete, and traverse items easily without needing contiguous memory space.

$\Large\textcolor{#2ea44f}{\textbf{stack ADT}}$

Study the Last-In, First-Out (LIFO) data pattern, similar to a stack of plates. You will learn how to build a stack and use push (add) and pop (remove) operations for real-world tasks like tracking history or undo functions.

$\Large\textcolor{#2ea44f}{\textbf{sorting algorithm 2}}$

Learn practical ways to arrange data into ascending or descending order using intermediate and advanced sorting techniques (such as Merge Sort and Quick Sort) to make searching and organizing data much faster.

$\Large\textcolor{#2ea44f}{\textbf{graph ADT}}$

Explore how to represent complex networks—such as social media connections, city roads, or computer networks—using nodes (points) and edges (lines connecting the points).

$\Large\textcolor{#2ea44f}{\textbf{time complexity}}$

This course introduces data structures and algorithms with a strong focus on time complexity, which is the measure of how fast your code runs as your data grows. You will learn how to analyze your code step-by-step using simple Big O notation, allowing you to easily spot slow programs and fix them. By the end of this course, you will understand how to choose the right data structures to make your software run quickly and efficiently.

$\Large\textcolor{#2ea44f}{\textbf{dynamic programming}}$

Master a method for solving difficult problems by breaking them into smaller sub-problems. You will learn how to save the answers to these sub-problems so you never waste computer power calculating the exact same thing twice.
